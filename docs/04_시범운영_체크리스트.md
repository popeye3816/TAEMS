# 시범 운영 체크리스트

PRD M7 완료 기준: **팀 전체가 한 달 동안 실제 업무에 쓴다.** 권장 기간: 2026-11-01 ~ 11-30 (12월 피크 전에 익숙해지도록)

## 시작 전 (관리자)

- [ ] 엔지니어·영업 계정 일괄 등록, 임시 비밀번호 전달 (사용자 관리 › 여러 명 한꺼번에 등록)
- [ ] 직원 명단에서 계정 없는 영업 담당자 이메일 입력
- [ ] 고객사 48곳 담당 엔지니어 확인, 2026-10-15로 들어간 인수인계 날짜 수정
- [ ] 점검 주기 '확인 필요' 14곳 확인 (고객사 › 점검·이슈 탭)
- [ ] 회사 표준 결과서 양식(.docx/.hwp) 업로드 (점검결과서 › 결과서 양식)
- [ ] 11월 일정 만들기, 담당·날짜 조정
- [ ] 알림 채널 중 최소 하나(메일 또는 카카오워크) 켜기, 시험 알림 확인
- [ ] 첫 백업 (`npm run backup -- --files`)
- [ ] 30분 사용 설명회 (docs/03_사용자_안내.md)

## 시범 운영 중 규칙

- 점검결과서는 **TAEMS에만** 올린다 (공유 폴더 병행 금지 → 정보 분산 재발 방지)
- 고객 문의·장애는 **전부 이슈로 등록**한다 (전화로 끝난 건도 사후 등록)
- 담당 변경, 고객 담당자 변경은 그날 고객사 화면에 반영
