작성 2026-10-15. 이 프로젝트는 교육 시간에 Claude Code 대화 하나로 M1~M7을 만들었다. 대화 기록은 다른 계정으로 옮겨지지 않으므로, 이어받는 사람(과 Claude)이 알아야 할 내용을 여기에 모았다.

## 1. 이어받는 방법

### A. 같은 PC, 다른 Claude 아이디

1. Claude 데스크톱 앱에서 다른 아이디로 로그인
2. Code 탭에서 이 폴더 `C:\Users\unipoint\Desktop\기술지원_통합관리시스템`를 연다
3. 첫 메시지: **"CLAUDE.md와 docs/05_인수인계.md를 읽고 현재 상태를 요약해 줘"**

같은 PC면 `.env.local`, `.secrets/`, Supabase·Vercel CLI 로그인, Git 로그인이 그대로 남아 있어 바로 작업할 수 있다.

### B. 다른 PC

1. 저장소 받기
   ```bash
   git clone https://github.com/popeye3816/TAEMS.git
   ```
2. `npm install` (Node 24 권장, Python 3.12 + `openpyxl`은 엑셀 가져오기 때만)
3. **비밀값 파일 옮기기** (git에 없음, 메일·메신저로 보내지 말 것 — USB나 회사 비밀번호 관리 도구로):
   - `.env.local` → 새 PC의 프로젝트 폴더에 그대로
   - 특히 `ENCRYPTION_KEY`가 없으면 고객 IP·계정을 복호화할 수 없다
   - 또는 Vercel에서 받기: `npx vercel login` → `npx vercel link` → `npx vercel env pull .env.local` (단 `--sensitive`로 넣은 SUPABASE_SECRET_KEY·ENCRYPTION_KEY·CRON_SECRET은 내려받기 안 됨 → 직접 옮겨야 함)
4. 각 서비스 로그인은 **사람이 직접** 한다 (Claude는 비밀번호를 입력하지 않는다)
   ```bash
   npx supabase login
   ```
   ```bash
   npx supabase link --project-ref puxtavhehglhymmjjtwo
   ```
   ```bash
   npx vercel login
   ```
   GitHub는 첫 `git push` 때 로그인 창이 뜬다 (popeye3816 계정 또는 쓰기 권한이 있는 계정).
5. Claude Code에서 폴더를 열고 A-3과 같이 시작

서비스 계정이 모두 chlee@unipoint.co.kr 소유이므로, 계정을 공유하지 말고 권한을 나눠 준다.
