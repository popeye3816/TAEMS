# TAEMS 사용 안내

주소: **https://taems.vercel.app** · 회사 이메일로 로그인 · 처음 받은 임시 비밀번호는 왼쪽 아래 이름 › **내 계정**에서 바로 바꿔 주세요.

## 엔지니어

**월 정기점검**
1. 대시보드의 "2주 안의 내 점검" 또는 **월별 일정 › 내 점검만**에서 내 점검을 확인합니다.
2. 날짜가 정해지면 일정 표에서 날짜를 넣고 저장합니다(상태가 '일정확정'으로 바뀜). 3일 전에 알림이 옵니다.
3. 점검을 열면 고객사 출입 절차·정기점검 방법·결과서 양식이 있습니다.
4. 점검 후 **결과서(PDF·Word·한글)와 사진을 올립니다.** 여러 개를 한 번에 올릴 수 있고, 올리면 영업 담당자에게 자동으로 알림이 갑니다.
5. 점검 중 문제를 발견하면 "점검 중 발견한 문제를 이슈로 등록"을 누릅니다.

**이슈**
1. **이슈 › 이슈 등록**: 고객사, 시스템, 심각도, 내용을 입력합니다. 입력하는 동안 비슷한 지식베이스 문서가 추천됩니다.
2. 배정되면 알림이 옵니다. 미배정 이슈는 직접 "내가 맡기"를 할 수 있습니다.
3. "처리 시작" → 처리 기록·로그·스크린샷을 남깁니다.
4. 완료할 때 **원인과 조치를 꼭** 씁니다. "지식베이스에 등록"을 체크해 두면 초안이 만들어지니 나중에 다듬어 게시해 주세요.

**고객사 정보**: 고객사 화면에서 시스템·버전, 담당자, 출입 절차를 최신으로 고쳐 주세요. 인수인계서 대신 이 화면이 기준이 됩니다. IP·계정은 담당 고객사만 "보기"로 볼 수 있고 열람 기록이 남습니다.

**지식베이스**: 증상·오류 메시지·제품명으로 검색합니다. 도움이 된 문서에는 "도움됨"을 눌러 주세요.

## 영업

1. 결과서가 올라오면 알림이 옵니다(시스템 알림, 메일·카카오워크가 설정된 경우 함께).
2. **점검결과서** 또는 **대시보드**에서 담당 고객사의 이번 달 결과서를 내려받아 대가 청구에 사용합니다. "서명본" 표시가 있으면 고객 확인 서명이 된 파일입니다.

## 관리자

- 매월 하순 **월별 일정 › ○월 일정 만들기** → 담당·날짜 조정. **업무량** 화면에서 몰리는 달(피크)을 미리 확인합니다.
- 이슈 배정, 미배정·지연 이슈 확인은 대시보드에서 합니다.
- 계정·직원 명단·알림 채널은 **사용자 관리**에서 관리합니다. 자세한 운영 방법은 `docs/02_운영가이드.md`.

## 문의

화면에 오류 번호가 나오면 그 번호와 함께 관리자(이충호)에게 알려 주세요.
